Enable Fair Sharing

In this section, you enable DRS-based fair sharing by patching the Kueue CR’s preemption policy.

References

  • Kueue: Fair Sharing

  • Kueue: Preemption

  • Red Hat build of Kueue: Configuring Fair Sharing

Lab: Enable Fair Sharing in Kueue Configuration

1. Enable fair sharing

  1. Clean up any running workloads from previous exercises:

    $ oc delete jobs --all -n training-jobs 2>/dev/null
$ oc delete deployments --all -n inference-apps 2>/dev/null

  2. Enable fair sharing:

    $ oc patch kueues.kueue.openshift.io cluster -n openshift-kueue-operator --type merge -p '{
  "spec": {
    "config": {
      "preemption": {
        "preemptionPolicy": "FairSharing"
      }
    }
  }
}'
kueue.kueue.openshift.io/cluster patched

  3. Verify:

    $ oc get kueues.kueue.openshift.io cluster -n openshift-kueue-operator \
  -o jsonpath='{.spec.config.preemption}' | python3 -m json.tool
{
    "preemptionPolicy": "FairSharing"
}

    You should see "preemptionPolicy": "FairSharing". The Kueue operator translates this into fairSharing.preemptionStrategies in the controller ConfigMap and restarts the controller automatically.

The cluster has two Kueue-related CRDs and they are easy to confuse:

CRD Resource name What it controls

kueues.kueue.openshift.io/v1

cluster

The Red Hat Kueue operator config (patch this one)

kueues.components.platform.opendatahub.io/v1alpha1

default-kueue

The RHOAI DataScienceCluster component (do not patch)

If you patch the wrong one, the change has no effect and produces no error. Always use kueues.kueue.openshift.io with --type merge.
Do not edit the kueue-manager-config ConfigMap directly to add fairSharing.enable: true (as shown in some upstream Kueue v1beta1 docs). This will crash the Red Hat Kueue v1.3.1 controller — it uses strict decoding and rejects the unknown field. Additionally, the openshift-kueue-operator pods actively reconcile the ConfigMap — any manual edits are overwritten within seconds. Always configure fair sharing through the Kueue CR.
Fair Sharing Preemption Strategies

When preemptionPolicy: FairSharing is set, the Kueue operator configures two preemptionStrategies in the controller ConfigMap. These strategies control when Kueue is allowed to preempt:

  • LessThanOrEqualToFinalShare: Preempt if the preemptor’s DRS after admission is less than or equal to the preemptee’s DRS after eviction. This is the primary strategy — it ensures the preemption makes the distribution more fair, not less.

  • LessThanInitialShare: Preempt if the preemptor’s DRS after admission is less than the preemptee’s current DRS. This is a fallback for edge cases where the first strategy cannot find a valid target.

Both strategies require reclaimWithinCohort: Any on the ClusterQueues to take effect.
