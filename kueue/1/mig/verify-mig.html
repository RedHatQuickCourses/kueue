Verify MIG Resources

After updating the topology ConfigMap and restarting the device-plugin, the node should advertise both whole GPU and MIG resource types.

References

  • NVIDIA: Multi-Instance GPU User Guide

  • Kubernetes: Extended Resources

Lab: Verify MIG Resources on the Node

1. Check MIG resources in node allocatable

$ oc get node $WORKER_NODE1 -o jsonpath='{.status.allocatable}' | python3 -m json.tool | grep -E 'gpu|mig'
    "nvidia.com/gpu": "3",
    "nvidia.com/mig-1g.5gb": "1",
    "nvidia.com/mig-2g.10gb": "1",
    "nvidia.com/mig-3g.20gb": "1",

Key observations:

  • nvidia.com/gpu dropped from 4 to 3 — GPU 0 is no longer a whole GPU

  • Three new MIG resource types appeared — these are schedulable like any other extended resource

  • Each MIG instance is fully isolated with its own compute and memory

You can also see the full picture with:

$ oc describe node $WORKER_NODE1 | grep -A 15 "Allocatable:"
